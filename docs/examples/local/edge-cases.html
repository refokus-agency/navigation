3 · Panel living in its item, viewport present but empty

A panel taking the in-item fallback got no hover target, so the close timer ran on and shut it ~150ms after the cursor arrived. Closing also snapped shut with no exit animation, while switching animated properly.

4 · Nested item inside a panel

A mega-menu column with its own [data-nav-item] used to register as a top-level trigger, but Tab excluded it — so Home/End could send focus to an element Tab could never reach, and nowhere at all when its panel was closed and inert.

Nested link

Focus Mega menu and press End → focus must stay on it. The check confirms the inner trigger got no aria-expanded and no data-state.
